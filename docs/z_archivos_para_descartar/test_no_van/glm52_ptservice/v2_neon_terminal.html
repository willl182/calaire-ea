// 06 confidencialidad & evaluación

Código controlado · sin calificación agregada

Confidencialidad · P-PSEA-19

Cada participante se identifica mediante un código controlado. La relación entre identidad y código se restringe al personal autorizado. Los informes y comunicaciones no revelan identidad ni resultados de otros participantes salvo autorización o deber institucional documentado.

Evaluación del desempeño

  • <12Menos de 12 resultados válidos: valor de referencia CALAIRE-EA.
  • ≥12Doce o más resultados: consenso robusto de participantes.
  • z'Indicadores z o z′ y, cuando la incertidumbre es utilizable, ζ y En.
  • --Sin calificación a1–a7 · sin aprobado/reprobado global.
