## 1. Objeto

Formato estándar que cada laboratorio participante debe completar y remitir al organizador con los resultados obtenidos del análisis de las muestras recibidas. Facilita la recopilación uniforme de datos y su procesamiento estadístico posterior.

## 2. Referencia Normativa

| Norma | Descripción | Aplicación |
|-------|-------------|------------|
| ISO 15189:2022 | Laboratorios clínicos — Requisitos de calidad y competencia | Información mínima del resultado |
| ISO 13528:2016 | Métodos estadísticos para resultados de PT | Formato de reporte para PT |
| ISO/IEC 17043:2023 | Conformidad — Requisitos generales para ensayos de aptitud | Obligación de reporte del participante |
