| Campo | Valor |
|-------|-------|
| **Código** | F-BIOA-07 |
| **Nombre** | Lista Maestra de Participantes — Bioanálisis Clínico |
| **Nivel** | 4 |
| **Estado** | Borrador |
| **Prioridad** | 🔴 Crítica |
| **Responsable** | Coordinador de Ronda |
| **Alcance** | Ronda Simple — Set de Sangre |
| **Laboratorio Organizador** | Laboratorio de Bioanálisis Clínico — Hospital Universitario San Vicente |

## 1. Objeto

Documento de control que registra la información actualizada de todos los laboratorios participantes en la ronda simple del programa piloto de ensayos de aptitud para bioanálisis clínico. Sirve como fuente única de verdad para la gestión de comunicaciones, envíos y seguimiento de resultados.

## 2. Referencia Normativa

| Norma | Descripción | Aplicación |
|-------|-------------|------------|
| ISO 15189:2022 | Laboratorios clínicos — Requisitos de calidad y competencia | Requisitos de participación y competencia |
| ISO/IEC 17043:2023 | Conformidad — Requisitos generales para ensayos de aptitud | Información mínima del participante |
| Resolución 1022 de 2015 | Requisitos para laboratorios clínicos en Colombia | Registro y habilitación |

## 3. Información Mínima por Participante

| Campo | Descripción | Obligatorio |
|-------|-------------|-------------|
| Código de participante | Identificador único asignado por el organizador | Sí |
| Razón social | Nombre completo del laboratorio o institución | Sí |
| NIT / Identificación | Número de identificación tributaria | Sí |
| Dirección | Dirección física del laboratorio | Sí |
| Ciudad / Departamento | Ubicación geográfica | Sí |
| Nombre del responsable | Director técnico o responsable de calidad | Sí |
| Cargo | Cargo del responsable | Sí |
| Teléfono | Línea directa de contacto | Sí |
| Correo electrónico | Email institucional | Sí |
| Acreditación INVIMA | Número de registro (si aplica) | No |
| Acreditación ONAC / ISO 15189 | Estado y número de certificado | No |
| Analitos ofertados | Lista de analitos que el laboratorio realiza rutinariamente | Sí |
| Metodologías empleadas | Equipos y métodos para cada analito | Sí |
| Ventana de análisis confirmada | Fecha límite para envío de resultados | Sí |
| Contacto alternativo | Persona de respaldo | Sí |
