## 1. Objeto

Documento que registra el procedimiento completo de preparación, alicuotado y etiquetado de los ítems (muestras de sangre) destinados a la ronda simple del programa piloto de ensayos de aptitud. Garantiza la trazabilidad desde la obtención de la matriz biológica hasta la distribución final.

## 2. Referencia Normativa

| Norma | Descripción | Aplicación |
|-------|-------------|------------|
| ISO 15189:2022 | Laboratorios clínicos — Requisitos de calidad y competencia | Preparación de muestras de referencia |
| ISO 13528:2016 | Métodos estadísticos para resultados de PT | Preparación de ítems para PT |
| ISO/IEC 17043:2023 | Conformidad — Requisitos generales para ensayos de aptitud | Requisitos del organizador para preparación |
