## 6. Cálculo de z-Scores

### 6.1 Fórmula

**z = (x_i − x_asignado) / σ_P**

Donde:
- x_i = resultado del participante
- x_asignado = valor asignado (concentración conocida)
- σ_P = desviación estándar de consenso o desviación esperada

### 6.3 Clasificación de Desempeño

| Clasificación | Criterio | Interpretación |
|---------------|----------|----------------|
| **S** (Satisfactorio) | |z| ≤ 2.0 | El resultado es consistente con el valor asignado |
| **Q** (Cuestionable) | 2.0 < |z| < 3.0 | El resultado requiere investigación |
| **I** (Insatisfactorio) | |z| ≥ 3.0 | El resultado presenta desviación significativa |
