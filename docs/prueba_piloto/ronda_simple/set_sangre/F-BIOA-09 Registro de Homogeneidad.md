## 1. Objeto

Documento que registra los resultados del estudio de homogeneidad de los ítems preparados para la ronda simple. Verifica que la variación entre alícuotas individuales del mismo lote sea suficientemente pequeña para no afectar la evaluación del desempeño de los participantes.

## 2. Referencia Normativa

| Norma | Descripción | Aplicación |
|-------|-------------|------------|
| ISO 13528:2016 §8.2 | Métodos estadísticos para resultados de PT | Criterios de homogeneidad |
| ISO/IEC 17043:2023 §6.4 | Conformidad — Requisitos generales para ensayos de aptitud | Requisitos de preparación de ítems |
| ISO 15189:2022 | Laboratorios clínicos — Requisitos de calidad y competencia | Calidad de muestras de referencia |

## 6. Criterio de Aceptación

Según ISO 13528 §8.2, la desviación estándar entre alícuotas (s_s) debe ser menor que **0.333 × EP** (Desviación Esperada), donde EP se define como la desviación estándar deseable para el ensayo de aptitud.

| Analito | EP (desviación estándar deseable) | 0.333 × EP | s_s (obtenido) | ¿Conforme? |
