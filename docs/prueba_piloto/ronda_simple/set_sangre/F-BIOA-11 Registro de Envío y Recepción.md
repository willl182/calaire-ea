## 1. Objeto

Documento que registra la trazabilidad completa del envío y recepción de las muestras de sangre destinadas a los laboratorios participantes. Garantiza la integridad de las muestras desde el despacho hasta la confirmación de recepción por cada participante.

## 2. Referencia Normativa

| Norma | Descripción | Aplicación |
|-------|-------------|------------|
| ISO 15189:2022 | Laboratorios clínicos — Requisitos de calidad y competencia | Transporte y manejo de muestras |
| ISO/IEC 17043:2023 | Conformidad — Requisitos generales para ensayos de aptitud | Distribución de ítems |
| Resolución 1022 de 2015 | Requisitos para laboratorios clínicos | Cadena de frío y transporte |
