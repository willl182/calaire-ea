**Prioridad:** 🔴 Crítica  

---

## 1. Propósito del formato

Formato para documentar y evaluar la homogeneidad de las muestras de suelo preparadas como ítem PT. Registra el estudio de homogeneidad entre sub-muestras (recipientes) del mismo lote, incluyendo la selección de sub-muestras de prueba, los análisis realizados, los resultados obtenidos y la decisión sobre aceptabilidad de la homogeneidad. Base para garantizar que las diferencias entre resultados de participantes no se deban a variabilidad entre unidades distribuidas.

## 4. Diseño del estudio de homogeneidad

### 4.1 Selección de sub-muestras de prueba

| Criterio | Definición |
|---|---|
| Número total de recipientes del lote | `[POR DEFINIR]` |
| Número mínimo de sub-muestras de prueba | Mínimo 10 o 10% del total (el mayor) — ISO 13528 A.5 |
| Número real de sub-muestras evaluadas | `[POR DEFINIR]` |
| Criterio de selección | `[-]` Aleatorias entre los recipientes preparados |
| Analitos evaluados | pH, MO, N total, P disponible, K intercambiable, CEC, textura |

### 4.2 Procedimiento de muestreo de prueba

- [ ] Se identificaron aleatoriamente los recipientes a evaluar usando tabla de números aleatorios o generador.
- [ ] Se extrajo la sub-muestra de prueba de cada recipiente siguiendo el protocolo estandarizado.
- [ ] Se preparó cada sub-muestra bajo las mismas condiciones (misma persona, mismo equipo, misma secuencia).
- [ ] Se analizaron todos los analitos en triplicado técnico para cada sub-muestra.
- [ ] Se registraron los resultados sin selección ni exclusión previa.
