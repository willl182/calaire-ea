**Estado:** draft — listo para diligenciamiento y aprobación  
**Prioridad:** 🔴 Crítica  

---

## 1. Propósito del formato

Formato para registrar y controlar la información maestra de todos los participantes del esquema CALAIRE-EA para la ronda de suelos. Incluye: datos institucionales, persona de contacto, equipos declarados, métodos de análisis, estado de confirmación de participación, y seguimiento a prerrequisitos. Funciona como registro central de trazabilidad entre el esquema y cada participante.
