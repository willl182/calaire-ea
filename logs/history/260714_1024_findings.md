# Technical Finding / Milestone

**Context**: CALAIRE-EA Commercial Service Artifacts — QMS code renumbering reconciliation + 16-item improvement implementation

## The Discovery

The implementation review (`logs/history/260714_0927_review-ptservice-art-impl.md`) identified 3 bloqueantes + 13 no bloqueantes + 1 problema crítico de coherencia con la renumeración QMS del 2026-06-14. La sesión actual implementó los 16 puntos + resolvió la incoherencia de códigos, llevando los 15 artefactos CS de versión 0.1 PLANNED a versión 0.2 DRAFT con guías de evidencia, controles endurecidos, y referencias QMS post-renumeración.

**Patrón clave descubierto:** la renumeración del QMS (matriz `docs/sgc/matriz_equivalencias_codigos_sgc_pea.md`, aprobada 2026-06-14) renumeró varios códigos, y al menos uno (`F-PSEA-13`) ahora es ocupado por un contenido diferente al que tenía antes (era paquete H/E, ahora es informe final; el paquete H/E migró a `F-PSEA-11`). El blueprint `ptservice_art_prop.md` arrastraba los códigos antiguos sin nota de renumeración, y los artefactos CS-01 a CS-15 los heredaron. La solución implementada:

1. **Tabla de equivalencias canónica** en `commercial_service/00_control/qms_code_equivalence.md` con los 17 códigos que引用an los artefactos, mapeados a su significado antiguo y vigente.
2. **Header uniforme** en cada CS: línea "QMS code reference" apuntando a la tabla + nota "(antiguo F-PSEA-XX)" en referencias puntuales cuando el significado cambió.
3. **Sub-sección 19.1** añadida al blueprint para que el documento maestro reconozca la renumeración.
4. **Fila ambigua en CS-11** (mezclaba `F-PSEA-05A` y `F-PSEA-04` en la misma celda) corregida a `F-PSEA-04` (vigente) + `F-PSEA-03` para registro.

## Patrones a preservar

1. **Header universal para artefactos CS:** `Status | Owner | Required before | Last revision | QMS code reference` en el front matter, y changelog inline (4-col table) al final.
2. **Bloqueante → evidencia → texto sugerido:** cuando un `[FILL]` es bloqueante, además del marcador se añade una columna "Evidence / input source" en la tabla + texto sugerido para guiar al implementador.
3. **Standard text compartido:** el "report-use reminder" aparece en CS-01 sec 9, CS-08 cl 16, CS-13 template. Cualquier modificación debe hacerse en los tres simultáneamente, registrado en cada changelog inline.
4. **Equivalencias QMS:** siempre que un artefacto引用 un `*-PSEA-NN`, agregar referencia a `00_control/qms_code_equivalence.md` para que el lector no quede atrapado por la renumeración.
5. **Restricted folders:** OWNERS.md per folder documenta per-file access; el "access-controlled" genérico del README no es suficiente cuando hay archivos con sensibilidad diferente (costos vs. identidad).
