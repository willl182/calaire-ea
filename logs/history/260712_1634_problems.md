# Problem Record (Troubleshooting)

**Severity**: High

## The Problem

The commercial artifact blueprint still named `docs/documentacion_sgc/` as its QMS source even after the repository was consolidated. The navigation map also described a planned `02_despliegue_rondas` path and linked to `fichas_resumen` pages no longer present in the active QMS tree.

## User-Requested Corrections

- Treat `docs/qms/` as the QMS source of truth.
- Adjust the proposal and artifact blueprint accordingly.
- Update `docs/qms/mapa_navegacion_sgc_pea.html`.

## The Solution / Workaround

Added an explicit document-precedence rule to the proposal and blueprint. Updated the map with a visible source banner, canonical active folders, current round-evidence path and non-broken detail-panel paths. Rendered the map through the T3 collaborative preview and confirmed 50 nodes with no runtime error.

## Learnings to Preserve

- A filesystem consolidation must be reflected in every governance and blueprint document, not only by moving files.
- Use one explicit QMS root and mark all other copies non-controlling.
- Commercial documents consume QMS requirements; they do not become a parallel QMS.
- Navigation maps must point to active canonical locations rather than historical convenience pages.
